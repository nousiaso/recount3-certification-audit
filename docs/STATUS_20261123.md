## Important limitation of the latest SRA scan

Its `has_specific_attributes` flag accepts broad keys including `disease`, `sample type`,
`organism`, and `first-line therapy`; it is **not** evidence for primary tumour at accession
level. The printed `previously_unattested_or_ambiguous` count means a broad attribute was
present, not that an ambiguity was biologically resolved. The `NONPRIMARY` detector looked
only for a restricted regex in attributes whose **key contains `tissue`**, so **zero flags
is not a sensitivity-certified negative**, especially for U-labelled prostate and normal
salivary examples already source-classified in V5. Do not use that zero to admit specimens.
